Card Wars Game

A console-based card game implementation in C++ featuring object-oriented design, file I/O, and interactive gameplay mechanics.

🎮 Game Overview

Card Wars is a console-based implementation of the classic card game "War". The game demonstrates advanced C++ programming concepts including object-oriented design, file I/O operations, data structures, and user interface design.

Console-based game interface with menu system

🛠️ Technical Features

Object-Oriented Design

Clean class hierarchy with Card, Player, WarGame, and HighScore classes demonstrating encapsulation and inheritance principles.

File I/O Management

CSV file handling for card decks and high score persistence, with error handling and data validation.

Game Logic

Card comparison algorithms, deck shuffling, and turn-based gameplay mechanics with comprehensive rule implementation.

High Score System

Persistent high score tracking with JSON and CSV support, including player statistics and game history.

Testing Framework

Comprehensive testing suite with automated test cases for all game components and edge cases.

User Interface

Interactive console menu system with input validation, error handling, and user-friendly navigation.

💻 Code Structure

The project follows clean code principles with well-organized header and implementation files:

CardWars/

    std::string Face() const;
    void Print() const;
    int Compare(Card& otherCard) const;
    
private:
    std::string _suit;
    std::string _face;
    int Value(std::string face) const;
};

Game Flow

1. Load card deck from CSV file
2. Shuffle deck using random algorithm
3. Deal cards to players
4. Compare cards and determine winner
5. Track scores and game statistics
6. Save high scores to persistent storage
7. Display results and menu options
