## 🎮 Featured Project: Card Wars

The portfolio prominently features my **Card Wars** game, a console-based card game built in C++ that demonstrates:

- **Object-Oriented Programming**: Classes for Card, Player, WarGame, and HighScore
- **File I/O**: CSV file handling for cards and high scores
- **Data Structures**: Vectors and custom data management
- **Game Logic**: Card comparison, shuffling, and scoring systems
- **User Interface**: Console-based menu system and user interaction

### Card Wars Features:
- Interactive menu system
- Card deck management and shuffling
- High score tracking and persistence
- Player vs computer gameplay
- Comprehensive testing framework

## 🚀 Getting Started

### Prerequisites
- A modern web browser
- Git (for cloning the repository)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Code-Juan/Code-Juan.github.io.git
   cd Code-Juan.github.io
   ```

2. **Open in browser:**
   - Simply open `index.html` in your web browser
   - Or use a local server for development:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   ```

3. **Visit the site:**
   - Local: `http://localhost:8000`
   - Live: `https://code-juan.github.io`
